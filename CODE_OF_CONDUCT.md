# Code of conduct

MeetingRecorder's community should be a respectful, useful place to collaborate.

Be considerate, assume good faith, welcome people with different experience levels, and focus criticism on ideas and code. Harassment, threats, discrimination, deliberate disclosure of private information, and disruptive behavior are not acceptable in project spaces.

If you experience or observe unacceptable behavior, report it privately to the project maintainer using the repository's available private contact or moderation channel. Reports will be reviewed in context and may result in a warning, removal of content, or exclusion from project spaces.

This code applies to issues, pull requests, discussions, and other spaces managed by the project.
